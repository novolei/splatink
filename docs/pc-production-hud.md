# Production combat HUD

The live Tab map follows `src/main.js:921/924`, `src/ui/diorama.js` and `styles/hud.css:609–678`; `main.js:1120` keeps the ordinary image map collapsed. The user requested a 90° vertical live 3D camera, which overrides the original `DIO_PITCH=1.1`. The native expanded layer projects five fixed player/Base slots through the actual rendered camera and hides the image map. It keeps the real ground point, cursor, snap, stems, jump arc and dead/BUSY slot identities. Source Diorama itself has no overlap solver; the native readable badge positions adapt the six-pass solver from the original expanded `hud.js:1210–1238`. The source corner image minimap remains available when Tab is closed.

`scripts/ui/hud_reticle.gd` ports production `src/ui/hud.js:804–1047` and `styles/hud.css:145–247/595–598`. Reticle geometry uses actual CSS pixels at the viewport center, independent of the menu/HUD `--u` scale. Cached paths and fixed controls cover shooter ring/ticks, blaster's normalized dashed ring, rounded roller brackets, independent dualies rings/lock diamond, slosher quadratic arch, splatling's eight-segment charge meter and charger's track/notches/charge bars. Source recoil/bloom/kick clocks, range and enemy targeting, full-charge flash, hit/kill/combo/large-hit feedback, spawn shield, sub-aim cost pill and low/full/empty ink states are connected. Color substitution changes only the source SVG ink fills and preserves black outlines and white gloss.

The tank is one small reusable shader quad with the original ten-segment wavy liquid surface, 90/7.5 slosh spring, 14/s level damping, source ink gradients, sub-cost stripe, gloss/rim and a fixed pool of up to 14 refill bubbles. It fades after 1.4 seconds of full idle ink. Source event clocks update scalars; firing creates no Control nodes.

Root calls `InkUI.update_combat_reticle(fragment)` after each render-frame aim query. `SplatMatchHud.update_combat_reticle` merges the recent frame and updates only this cluster, while roster/map work stays on its lower cadence. Fields are `crosshair:{spread:screenPixels,onTarget:'enemy'|'none',inRange:bool}`, `weapon`, `charge`, `weapon_state:{lock,dodge,burst/streaming,aiming_sub}`, `alive`, `invuln`, `ink`, `max_ink`, `subCost` (fraction), `inkLow`, `aim_yaw`, `velocity`, `camera_right`, `team_color` and `enemy_color`. Native `weapon:shot/flick/beam` events map to the original weapon-fire kick, and attacker-local hit/splatted events drive confirmations. Map/intro/death hides the cluster. Boss nodes without player identity fields are safely handled by `hud_events.gd`; they cannot invoke `bool(null)` or `int(null)`.

Normal black shadows and hit/full-charge flashes use the source stack and clocks. The blur helper now requests `UPDATE_ONCE` only when the mask geometry or shadow stack changes; final opacity is applied by the resolve quad without re-rendering static filters. A visible rotating shield still refreshes its own three surfaces. `--profile-render` enables RenderingServer CPU/GPU timers for all ten pooled auxiliary surfaces; `InkUI.combat_profile_metrics()` also reports reticle/helper/mask script CPU and geometry/filter cache counters. Last timer values can be stale on cached surfaces, so recent timer values are separated for per-frame aggregation. There are no texture readbacks.

Root's clean `shots/pc-boss-reticle-cached-profile.json` measured recent auxiliary GPU median 0 ms / p95 0.096 ms / maximum 0.197 ms in one Windows RTX 5090 Boss run. Reticle script CPU was median 0.050 ms / p95 0.077 ms; the run reached 709 filter batches and 1506 geometry cache hits. This is a scene-specific measurement of the new helpers, not a cross-device performance promise. Historical `fps_average` values that sample `Performance.TIME_FPS` are monitor means; they should not be described as frame-count/elapsed-time averages.

Colorized reticle SVGs use byte-identical raw text companions `assets/ui/source_raw/sub_bomb.svg.txt` and `splat_icon.svg.txt`, because Godot can omit imported `.svg` source bytes even with an include filter. The original imported textures remain unchanged. A missing, empty or invalid raw companion now emits one clear error per path and yields no replacement icon; an export omission must be fixed in the package, not hidden by a different icon.

The Tab finish uses a nine-tap approximation of CSS Gaussian blur. Static screenshots and deterministic state checks do not establish all timing combinations, full game parity, or 100% pixel equality.
