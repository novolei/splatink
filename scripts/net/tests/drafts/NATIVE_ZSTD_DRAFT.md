# Unpublished bounded native tick compression draft

These retained draft scripts are not imported by the production adapter. This document records the earlier, pre-wiring experiment. A separate developer opt-in candidate now uses copies under `scripts/net/`; see [the production-path verification instructions](../NATIVE_ZSTD_CONTRACT.md). The original native framing remains the default and WebSocket/WSS relay behavior is unchanged. No new adapter or two-device result is claimed by this historical draft record.

The preceding `pc20261004c` JSON assertions passed on both endpoints (host45/guest44), including all eight real native animation providers, but the Mac host stdout reported two ObjectDB instances leaked at shutdown. That run is **not accepted as fully clean**. Root is collecting verbose object identities before changing lifecycle code. Compression cannot repair or hide that shutdown issue.

Its independently readable receive telemetry justifies a transport experiment: host sent131 fragmented ticks/279 parts; guest completed58 frames and evicted34 partial frames for capacity, with no timeout/rejected/pending frames at its checkpoint. Guest receive source gaps had median69ms, p95 approximately276ms and max603ms; arrival gaps had median69ms, p95 321ms and max604ms. Reverse-direction single packets completed129 frames with source median69ms and arrival p95 117ms. Counters were sampled independently on each machine, so they are not an exact packet-loss ratio and do not establish the underlying cause. ZSTD measurements over the current seven host-owned actor rows reduced the estimated wire budget1508→468 bytes without stats and2028→556 bytes with stats; ten-iteration mean encoding was10.8–13.4µs and decoding2.3–2.7µs on that host. These are fixture samples, not a general latency or device-performance guarantee.

`native_zstd_tick_codec.gd.encode(sender, source_tick, sequence)` returns ordinary source ticks unchanged when they already fit. For oversized ticks it preserves `var_to_bytes(source_tick)` exactly, compresses with ZSTD and selects one envelope only if the serialized RPC arguments plus the existing64-byte reserve fit1200 bytes. Identity sizing still reserves the full ten-character authenticated peer ID. The envelope is `{k:'t', ts:source_time, _nz:[1, sequence, raw_size, raw_hash, compressed_hash, compressed_bytes]}`. The hashes detect corruption; room membership remains the authentication boundary. Full uncompressed output is capped at64KiB. Unsupported values or compression that cannot fit one packet fall back to **exactly** `InkNativeTickCodec.split`, preserving actor rows and original metadata.

`native_zstd_tick_inbox.gd` extends the existing inbox for draft testing. The caller must `authorize_sender` only after ENet RPC sender authentication and room membership checks; at most eight canonical positive31-bit IDs are retained. Unknown senders allocate no output. Compression version, sequence, timestamp, packet budget, field types, hashes and advertised length are checked before applying any frame. Small, fragmented and compressed frames share the existing timestamp ordering; compressed and fragmented frames also share completed sequence ordering. Disconnect/room clear remove authorization, ordering and partial-frame state. A reconnect must be authorized again.

`zstd_frame_guard.gd` first checks Godot's dictionary-free single-segment frame, its advertised content size, bounded block structure and exact endpoint with no trailing/concatenated frames. Decode uses `decompress(raw_size, COMPRESSION_ZSTD)` only after the frame and envelope agree on a1..65536 byte output limit. The returned length and raw hash must match. `variant_bytes_guard.gd` preflights the entire bounded byte stream before object-disabled `bytes_to_var`: finite primitives, ordinary Array/Dictionary, valid UTF8 and numeric/string packed arrays; depth≤32, nodes≤8192, exact byte consumption. Typed containers and object/math/resource values are deliberately not compressed in this first draft; the encoder falls back without altering them. Restored tick kind/timestamp, unique actor indices and all original numeric snapshot fields must validate before the inbox changes its timeline.

The guard follows the official [Godot4.7 Variant decoder](https://github.com/godotengine/godot/blob/4.7/core/io/marshalls.cpp) and [bounded PackedByteArray decompression implementation](https://github.com/godotengine/godot/blob/4.7/core/variant/variant_call.cpp#L750), with the frame layout from the [ZSTD format specification](https://github.com/facebook/zstd/blob/dev/doc/zstd_compression_format.md). Native entropy decoding still uses Godot/ZSTD; this is not a custom compression algorithm.
